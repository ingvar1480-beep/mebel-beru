# Мебель-Беру

Статический сайт-каталог мебельного магазина. Для локального просмотра откройте `index.html` в браузере или запустите любой статический веб-сервер в этой папке.

Товары, цены, сроки и изображения в `app.js` демонстрационные; контактные данные нужно добавить после получения от владельца. Выбор вариантов на карточках предназначен для просмотра и не оформляет заказ. Фотографии загружаются с Unsplash, шрифты — с Google Fonts.

Проект можно развернуть в Vercel без сборки: импортируйте репозиторий и выберите Framework Preset **Other**.

## Настройка Supabase

1. В SQL Editor проекта один раз выполните `supabase-setup.sql` целиком. Скрипт создаёт таблицы, политики и хранилище; повторный запуск политик без их удаления вызовет ошибку.
2. В Authentication → Providers → Email отключите самостоятельную регистрацию (Allow new users to sign up). В Authentication → Users создайте пользователя администратора с подтверждённой почтой и сохраните его UUID.
3. В SQL Editor выполните `insert into public.admins (user_id) values ('UUID_ПОЛЬЗОВАТЕЛЯ');`, заменив UUID на скопированный из Authentication → Users. Не используйте пароль в SQL или исходном коде.
4. Откройте сайт: вход — Ctrl+Shift+M или значок возле копирайта. После входа доступны добавление, изменение и удаление товаров и заготовка календаря.

До настройки базы показываются демонстрационные товары. После создания таблицы каталог пуст и заполняется администратором. Фотографии загружаются в публичное хранилище (JPG, PNG, WebP до 5 МБ); удаление товара не удаляет файл фотографии автоматически. Публичный ключ Supabase предназначен для браузера; права на запись обеспечиваются RLS и таблицей `admins`. Пароль и секретные ключи не добавляются в репозиторий.
